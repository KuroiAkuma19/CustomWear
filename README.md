# 👕 3DClothing - CustomWear

A modern, responsive e-commerce platform for high-quality apparel. **3DClothing** features a sleek dark UI, interactive product displays, and a seamless shopping experience.

🚀 **Live Demo:** [kuroiakuma19.github.io/CustomWear/]

---

## ✨ Features

* **Premium UI/UX:** Dark-themed, modern interface built for readability and engagement.
* **Dynamic Product Catalog:** Categorized sections for "Top Selling Products" and "Best Products" featuring custom prints and textures.
* **Interactive Elements:** Responsive buttons, hover effects, and a testimonial slider.
* **Promotional Sections:** Integrated marketing banners for summer sales and discounts.
* **Fully Responsive:** Designed to work perfectly on desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** React.js + Vite
* **Styling:** Tailwind CSS 
* **Icons & Assets:** React Icons, Custom 3D Graphics
* **Deployment:** GitHub Pages
